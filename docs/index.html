로컬 콘솔

Features

하나의 유스케이스, 두 가지 실행 방식

검색 결과의 제목·링크·발행일·요약을 수집하고, 실행 환경에 맞는 발행 어댑터로 전달합니다.

⌨

대화형 콘솔 검색

Scanner로 검색어와 1~100개의 결과 수를 입력하고 콘솔에서 바로 확인합니다.

N

네이버 API 수집

JDK HttpClient로 뉴스 검색 API를 호출하고 HTML 태그와 주요 엔티티를 정제합니다.

#

GitHub Issue 발행

검색 결과를 Markdown으로 변환하고 검색 주제와 날짜가 포함된 Issue를 자동 생성합니다.

↕

정확도순 · 최신순

콘솔은 SIM, 자동화는 DATE를 사용해 목적에 맞는 정렬을 선택합니다.

17

표준 API만 사용

record, text block, HttpClient 등 JDK 17 기능만으로 HTTP와 JSON 처리를 학습합니다.

↻

주기적 자동 실행

GitHub Actions가 컴파일과 실행을 담당하며 수동 실행과 cron 예약 실행을 지원합니다.

Architecture

바깥 기술이 안쪽 정책을 향하는 구조

구체적인 API와 출력 방식은 애플리케이션 포트에 맞춰 구현됩니다. 핵심 모델과 유스케이스는 외부 기술을 알지 않습니다.

presentation · infrastructure→application 포트→domain

01 · DOMAIN

핵심 데이터와 규칙

NewsResult record가 결과와 문자열 정제를, NewsCategory enum이 SIM·DATE 조건을 표현합니다.

외부 기술 미의존

02 · APPLICATION

유스케이스와 포트

NewsService가 수집과 발행을 조정하고 NewsProvider·NewsPublisher 계약을 정의합니다.

DIP 경계

03 · INFRASTRUCTURE

외부 연동 어댑터

NaverNewsProvider가 수집 포트를, GitHubIssuePublisher가 발행 포트를 구현합니다.

API 교체 가능

04 · PRESENTATION

실행 진입점

ConsoleNewsApp과 AutomationNewsApp이 환경에 맞는 포트 구현체를 조립합니다.

입력 방식 교체

NewsProvider · 수집 포트

현재 네이버 어댑터 대신 다른 뉴스 공급자를 구현해도 NewsService는 바뀌지 않습니다.

NewsPublisher · 발행 포트

콘솔과 GitHub Issue뿐 아니라 파일·메신저 발행도 새 어댑터 추가로 확장할 수 있습니다.

Exercise Roadmap

4단계로 완성하는 실습

안쪽 모델에서 시작해 동작을 빠르게 검증한 뒤, 로컬 앱을 자동화 환경으로 이전합니다.

1

약식 클린 아키텍처 구현

domain 핵심 모델 → application 포트와 유스케이스 → infrastructure 어댑터 → presentation 진입점 순서로 구현하며 의존성 방향을 고정합니다.

2

임시 main 메서드로 중간 검증

아직 TDD나 테스트 프레임워크를 도입하지 않습니다. 각 컴포넌트 직후 작은 입력과 출력을 직접 확인하고, 검증이 끝나면 임시 main을 제거합니다.

3

Scanner 기반 콘솔 앱 완성

검색어와 개수를 입력받아 NaverNewsProvider와 ConsolePublisher를 조립합니다. 로컬 검색은 정확도순 SIM을 사용합니다.

4

GitHub Actions 자동화로 이전

Scanner를 환경변수로, 콘솔 발행을 GitHub Issue 발행으로 교체합니다. 동일한 NewsService를 수정하지 않고 최신순 DATE 수집을 자동화합니다.

Quick Start

환경변수 설정과 실행

JDK 17과 네이버 개발자센터에서 발급한 Client ID·Client Secret이 필요합니다.

  1. 샘플 파일 복사

    cp .env.sample .env

  2. 인증정보 입력

    NAVER_CLIENT_ID=발급한_Client_ID
NAVER_CLIENT_SECRET=발급한_Client_Secret
NEWS_QUERY=인공지능
NEWS_DISPLAY=10
GITHUB_TOKEN=
GITHUB_REPOSITORY=owner/repo

    .env에는 인증정보가 포함되므로 커밋하지 않습니다.

  3. IntelliJ 실행 구성 연결

    Run → Edit Configurations…에서 Application을 추가하고 아래 항목을 지정합니다.

    • Main class: oop.scraper.presentation.ConsoleNewsApp
    • JRE: 17
    • 환경변수 파일: 프로젝트 루트 .env의 절대경로
    • Working directory: 프로젝트 루트

Console mode

검색어와 개수를 입력하세요

실행 후 키워드와 1~100 사이의 검색 개수를 입력하면 정확도순 결과가 콘솔에 출력됩니다.
